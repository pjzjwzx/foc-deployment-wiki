### [3.2 逆 Park、SVPWM 与 PWM 输出](01-pwm-svpwm.md) · LAB1

**1.1 工程问题与通路。** 用一条图串起 dq 电压请求、静止坐标系电压、三相参考、占空比和桥臂脉冲。解释逆 Park 怎样把转子坐标系的请求转到定子坐标系，以及 SVPWM 怎样用三相占空比产生所需的相间平均电压。

**1.2 高层代码领读。** 沿 `Foc_VoltageStep()` 读电压限幅、逆 Park 和 min/max SVPWM。取 `Vd = 0 V`、`Vq = −2 V`、`θe = π/2`、`Vbus = 12 V`，限幅内的输入经逆 Park 得到 `(Vα, Vβ) = (2, 0) V`，再投影为三相参考 `(2, −1, −1) V`。三相同时减去 `(vmax + vmin)/2 = 0.5 V`，保留相间电压差。各相除以母线电压、加 `0.5` 并限到 `[0, 1]`，得到 `duty = (0.625, 0.375, 0.375)`。3.3 的电压开环和 3.7 的电流闭环都沿用这条输出链。 [调制源码](https://github.com/pjzjwzx/foc-stm32-example/blob/chapter-3/control/foc.c)

**2.1 BSP 与 CubeMX 领读。** 沿 TIM1 的中心对齐、PWM2、通道极性、死区和预装载配置，读到 BSP 写入三相比较值。沿用上一段算例，本例 `ARR = 6000`，按 `CCR = (1 − duty) × ARR` 得到 `(CCR1, CCR2, CCR3) = (2250, 3750, 3750)`。 [板级 PWM 写入](https://github.com/pjzjwzx/foc-stm32-example/blob/chapter-3/bsp/board.c)

**2.2 LAB 实机操作与验收。** 在板卡允许控制侧独立运行的条件下，保持功率断开和驱动关闭，运行 LAB1。用当次测试输入对应的 duty 核对 MCU 引脚的载波周期、通道顺序和脉宽。驱动状态异常时停止检查。

### [3.4 电流与角度传感器](03-sensors.md) · LAB3

**1.1 工程问题与通路。** 在 Simulink 里，可以直接从电机模型拿到安培值。实物里，电流流过采样电阻，在两端产生小电压。放大器把它放大并加上偏置，ADC 再把电压变成计数。程序先减去零电流时的计数，乘上每计数代表的电压，再除以放大倍数和采样电阻，按相序和正方向得到相电流。角度也要经过一条测量通路。编码器读数转换成约定方向的机械角后，随时间戳和有效标志一起交给控制。 [ST 电机电流采样示例](https://www.st.com/resource/en/user_manual/um1052-stm32f-pmsm-singledual-foc-sdk-v43-stmicroelectronics.pdf)

**2.1 BSP 与 CubeMX 领读。** 从 ADC 通道和过采样配置读到三相计数的排列，用本板参考电压、有效满量程、放大倍数和分流电阻解释 A/count。再沿 SPI 编码器驱动读角度字段、有效标志与时间戳的交付。

**2.2 LAB 实机操作与验收。** 用 LAB3 保持关桥并等待零偏完成，观察三相电流是否接近 0 A。机械装置允许时缓慢手转，检查角度方向和跨圈。读数贴住量程端点或偏置明显时，先查测量链再继续。

### [3.5 采样、中断与一拍控制](04-sampling-zero.md) · LAB4

**1.1 工程问题与通路。** 电流环按固定采样间隔工作。定时器选在 PWM 的指定位置触发 ADC，数据要经过转换才可用。用两张时间轴区分采样时刻、数据就绪、控制开始、提交截止和 PWM 生效。

~~~text
采样完成启动控制
定时器触发采样 → ADC 转换 → 本帧电流到齐 → 启动电流环 → 提交 duty → PWM 更新

定时器直接启动控制
定时器触发采样 → ADC 转换 → 选定的采样帧已就绪 → 预定的定时器中断运行电流环 → 提交 duty → PWM 更新
~~~

采样完成启动控制时，固定的是采样间隔，转换耗时和中断响应影响控制开始的时刻。用定时器中断直接运行控制时，需要按最迟的数据就绪时刻安排中断，并约定使用本帧还是上一帧。若使用上一帧，要把多一拍的反馈延迟算进去。本工程用一组新电流到齐作为控制开始的条件。

**1.2 高层代码领读。** 从 `MotorApp_CurrentIsr()` 接收三相计数和触发参考时间读起，跟到电流换算、反馈角选取、控制计算和板级提交请求。读清提交失败时应用怎样进入故障关断。

**2.1 BSP 与 CubeMX 领读。** 沿 TIM1 CH4/TRGO、ADC 注入组和 NVIC 配置，追到 IRQ 入口与三路转换完成回调。读 BSP 怎样汇齐一帧再调用应用。本例完整载波周期为 50 μs，从载波底端起算，CCR 预装载必须在约 23 μs 的提交门槛前写入，到约 25 μs 的上端点锁存。 [采样回调与 PWM 提交源码](https://github.com/pjzjwzx/foc-stm32-example/blob/chapter-3/bsp/board.c)

**2.2 LAB 实机操作与验收。** 用 LAB4 在 Disabled 下先核对采样节拍。满足 3.3 的启停条件后再短时开环，记录帧就绪、控制执行、提交和锁存的相对时刻。每个载波对应一拍控制，且最晚的提交仍在截止前，即通过。发现节拍异常、提交超时或故障时停机。

## 第四章　滤波与编码器位置、速度估计

用有真值的测试信号比较方法。电流滤波和速度估计各画一张 **Pareto 图**，横轴为等效延迟，纵轴为稳态残余噪声 RMS。每组参数对应一个点。在相同延迟下比较噪声，在相同噪声下比较延迟，再结合加减速时的位置误差选参数。

| 小节 | 重点 |
|---|---|
| **4.1 怎样测噪声和延迟** | 保留原始信号作基线。用稳态段量残余噪声，用固定测试频率的相位差换算等效延迟。 |
| **4.2 电流滤波** | 对比因果滑动平均与一阶低通，扫描窗口长度和截止频率，观察降噪以及电流反馈变慢的程度。 |
| **4.3 编码器测速基线** | 从角度展开、按实际时间戳差分、低通和位置外推入手，观察低速量化、跨圈和加减速。 |
| **4.4 编码器 PLL** | 用环形角度误差跟踪位置和速度，观察环路带宽对噪声和跟踪延迟的影响。 |
| **4.5 Kalman 滤波** | 用角度和速度两个状态、编码器角度一个观测，比较不同固定 `Q`、`R` 设置的结果。 [编码器测速研究](https://journals.sagepub.com/doi/10.1177/027836499801701107) |
| **4.6 自适应 Kalman（fading）** | 在同一模型上，用测量角度与预测角度之间的差值（创新）调整 fading 因子。与固定参数 Kalman 对照，观察加速后的跟踪和回到稳态后的噪声。 |
| **4.7 RLS 拟合测速** | 对展开后的角度随时间做带遗忘因子的递推拟合，用斜率估速度，比较记忆长度的影响。 |
| **4.8 广义比例积分观测器（GPIO）** | 只用编码器角度，建立运动学积分链，把未知加速度作为扩展量，比较不同观测器带宽。 |
| **4.9 用 Pareto 前沿选参数** | 同类方法使用相同采样、噪声和运动轨迹。除两张 Pareto 图外，再对照加减速、反转和跨圈时的位置误差。 |

## 第五章　理解离散控制

- **5.1 连续对象怎样按拍运行**　用一条时间轴标出采样、计算、零阶保持和输出生效。区分采样周期与实际执行延迟。
- **5.2 从电流方程到差分方程**　用单轴 RL 电流模型写出从这一拍到下一拍的更新式。再回看第三章的数字 PI，解释采样周期怎样进入积分，延迟怎样影响响应。
- **5.3 用 DPCC 理解预测控制**　从离散模型预测下一拍电流，再反求所需电压。用一拍执行延迟演示怎样用当前施加的电压预测下一拍电流，再据此计算下一次电压指令。 [DPCC 与一拍延迟研究](https://ieeexplore.ieee.org/document/7515145/)
- **5.4 PI 与 DPCC 仿真对照**　用独立的电流环小模型，在相同采样周期、电压限幅和电流阶跃下，比较标称参数、一拍延迟和电机参数偏差三种情况。观察跟踪速度、超调和饱和。
