第 3 章 · 3.4

3.4 电流与角度传感器

上一节 3.3 电压开环 · 下一节 3.5 采样、中断与一拍控制

电流环要用安培值和转子角。这一节先解释板子怎样得到这两个量，再读固件怎样把它们交给控制。

1.1 工程问题与通路

在 Simulink 里，可以直接从电机模型拿到安培值。实物里，电流流过采样电阻，在电阻两端产生一个小电压。放大器把它放大并加上偏置，ADC 把电压变成计数。电流为零时，放大器和 ADC 仍可能给出一个非零计数，这个基线要先减掉。

相电流 → 采样电阻两端电压 → 放大与偏置 → ADC 计数
      → 减零电流基线 → 换算为安培并统一相序与正方向

计算时，计数差乘上每计数对应的伏数，再除以放大倍数和采样电阻。举个只用于理解换算的例子，若采样电阻为 1 mΩ，放大倍数为 50，1 A 对应放大后的 50 mV 变化。在本例板上，增益和刻度取自 2.1 的实际配置。 ST 电机电流采样示例

角度也经过一条测量链。编码器读数转换成约定方向的机械角后，随时间戳和有效标志交给控制。两份数值相同的角度，如果取样时间不同，对这一拍控制的意义也不同。

1.2 高层代码领读

从 ADC 计数还原三相电流

应用收到一帧 ADC 计数后，先按约定相序转换为有符号的电流。本工程中数组下标 0、1、2 对应 A、B、C，进入控制算法前先把采样计数换成 A。 应用采样入口

源码摘录。在 MotorApp_CurrentIsr 逐相处理当前帧，以下两行算电流并记录结果，中间的过流检查略去。

phase[i] = ((float)raw[i] - (float)MotorApp_Diagnostics.adc_zero[i]) *
           BOARD_CURRENT_A_PER_COUNT * BOARD_CURRENT_SIGN;
MotorApp_Diagnostics.phase_A[i] = phase[i];
  1. raw[i] 是这一相本拍的 ADC 计数。adc_zero[i] 是同一相在零电流时测到的基线。先转成 float 再相减，保留低于基线时的负值。
  2. 对采用分流电阻和放大器的电路，电流先经分流电阻 Rshunt 变成电压，再经放大器增益 G 送进 ADC。换算系数为 ADC 每计数的伏数 ÷ (G × Rshunt)，单位是 A/count。最后乘接线约定的符号。
  3. 结果既写到诊断量，也保留在 phase[3]，随后由 Foc_Measure(&foc, phase, angle) 读取。零偏完成后，任一相的电流绝对值超过所选电机配置的阈值会触发故障关桥。Open 分支仍用 open_angle 计算电压。 换算后的控制去向

零偏来自上电后关桥的实际样本。应用进入 APP_OFFSET，每帧把三相分别加到 offset_sum[i]。达到 FOC_CURRENT_OFFSET_SAMPLES 后，分别用整数除法保存三相均值，切到 APP_DISABLED。本工程是 2048 帧，若每帧相隔 50 μs，累计窗口约为 102.4 ms。读波形时从完成偏置之后开始看。换板时从电路和 ADC 输出刻度重算比例，测量链在基线以外还要检查饱和、相序及正负方向。 零偏状态与切换 · 样本数

把转子角当作带时间的样本

应用需要电机轴机械角。一圈是 2π rad，从输出轴换算时还要考虑减速比。角度样本也携带取得时间、方向和有效状态。

源码摘录。每拍从 MotorApp_CurrentIsr 进入 encoder_tick，以下是接收后进入更新的入口。

EncoderSample_t sample;
Encoder_TakeSample(&sample);
if (sample.fresh)
{
    if (sample.valid && Rotor_Update(&rotor, sample.raw_u16, sample.timestamp_us))

EncoderSample_t sample 为本次调用留出一份结构体。&sample 把它的地址交给驱动，驱动通过地址写回数据。fresh 表示取到新完成的帧，valid 表示该帧可用。&& 会先检查左边，校验失败时跳过 Rotor_Update。此时结构体里的 raw_u16 可能仍是上次好帧的角，不能当成新位置。 应用接收与健康检查 · 驱动写回

Rotor_Update 先检查时间戳，再把原始角统一成约定方向的全圈计数，随后把修正后的计数乘 2π/65536，得到机械弧度。没有启用 LUT 时，修正步骤直接返回方向归一化后的计数。rotor->sample_time_us 和 rotor->valid 随成功更新一起写入。实际电流环和角度采样可以有不同周期。更换传感器时，先确定一圈的计数、方向、样本时间的定义和有效条件，再决定控制环可以使用多旧的样本。 角度方向与更新

应用收到什么、记录什么

物理量 进入应用时的量 转换后查看
ia、ib、ic，A raw[0..2]，各相采样计数 MotorApp_Diagnostics.phase_A[0..2]，A
单圈机械角，rad sample.raw_u16，全圈统一刻度 rotor.raw_angle_u16 已统一方向，rotor.mechanical_angle_rad 还包含可能的 LUT 修正
采样时刻，s sample.timestamp_us，μs rotor.sample_time_us，随最近有效角更新

2.1 BSP 与 CubeMX 领读

电流通道和板级比例

H743 示例板的三个注入组分别取 A 相 PB1/ADC1 IN5、B 相 PA7/ADC2 IN7、C 相 PC2_C/ADC3 IN0。CubeMX 的 Pinout & Configuration → Analog → ADC1/ADC2/ADC3 中，先核对引脚、单端通道和注入 Rank 1。生成的 MX_ADCx_Init 分别写入 ADC_CHANNEL_5、ADC_CHANNEL_7、ADC_CHANNEL_0。三路结果进入 raw[0..2]。这一节先核对通道与量纲，下一节再按一整拍讲触发和中断。 本板 .ioc · 三路 ADC 配置 · 读取三路结果

board_config.h 使用 3.0 V 参考、0.5 mΩ 分流电阻和外置 INA241A3 的 50 V/V 增益。14 bit 的单次转换最大码为 16383，注入结果以 16 次累加后右移两位，满刻度是 16383 × 16 ÷ 4 = 65532 counts。因此程序使用 3.0 ÷ (65532 × 50 × 0.0005) ≈ 0.00183117 A/count，并设符号为 +1。启动中的 HAL_ADCEx_Calibration_Start 校准 ADC 本身，应用稍后求的 adc_zero[] 包含整条电流测量链的基线。 板级参数 · ADC 硬件校准

TLE5012 角度怎样交给应用

本例用 SPI1 单数据线发命令、收角度。DMA 在外设和内存间搬运字节，应用不在电流回调中等待整帧传完。驱动请求时记下 MCU 微秒时间并拉低片选，TX 完成后切换为 RX，接收角字段和安全字。之后取样入口校验 CRC、状态和角字段，把结果和请求时间戳交给应用。故障恢复期间也可能收到一帧但没有可用新角。 发起请求 · TX、RX 事务 · 角字段与有效位

应用每五个 20 kHz 电流节拍请求一次新角，名义间隔 250 μs。连续收到 8 个坏帧，或在运行时有效角缺失、样本年龄超过 10 ms，都会走编码器故障路径。 应用接收与健康检查 · 调度分频

CubeMX 的 Connectivity → SPI1 配置与生成代码的对应关系如下。其他传感器也需要提供同样的角度样本接口，通信方式、供电、电平与引脚由目标板决定。

核对位置 本工程取值与用途 生成代码
Pinout PB3 是 SCK，PD7 是单线数据，PA15 是软件控制的片选，空闲高 SPI 引脚复用 · PA15 初值
SPI1 Parameter Settings Master、1 Line、8 Bits、CPOL Low、CPHA 2 Edge、MSB First、Software NSS。SPI123 时钟 48 MHz，除 8 得 6 MHz 位时钟 SPI1 参数 · 时钟设置
SPI1 DMA Settings RX 用 DMA1 Stream3，TX 用 Stream4，Normal 模式，内存和外设均按 Byte 搬运 DMA 初始化与句柄关联
NVIC Settings SPI1 和 DMA1 Stream3/4 的抢占优先级都是 2，低于电流采样 IRQ 的 1 SPI1 NVIC · 中断配置

角字段有效后，驱动取低 15 位的角度字段并左移一位，让一圈采用统一的 uint16_t 刻度。应用里的 BOARD_ENCODER_REVERSE=1 再用模一圈的减法统一方向。6 MHz 描述一次 SPI 事务内的位速率，4 kHz 描述应用名义请求频率。驱动若忙，实际间隔要看记录的时间戳。 TLE5012 角度掩码 · 角方向

手算检查

  1. 一相零偏为 32768、当前原始码为 32668，得到多少 A。答案　差值 −100 counts，乘本板系数后约 −0.183 A。
  2. TLE5012 的有效角字段为 0x6000，开启反向且未启用 LUT，得到什么机械角。答案　统一刻度为 0xC000，反向为 0x4000，即四分之一圈 π/2 rad。
  3. 新帧的 fresh=1、valid=0，如何更新机械角。答案　不调用 Rotor_Update，保留上次有效角，并累计坏帧。手转波形停住时，应同时查有效帧和样本年龄。

2.2 LAB 实机操作与验收

实物选做｜先关桥手转，再短时开环

  1. 以 LAB_STAGE=3 构建并下载，按上一节的 UART4 接法观察 JustFloat 波形。上电后保持 Disabled，等零偏采集完成。在调试器中看 MotorApp_Diagnostics.adc_zero[0..2]，对照波形 ch0、ch1、ch2 应在 0 A 附近。若某相原始读数一直贴近量程端点，或关桥后仍有明显偏置，先停止并查引脚、前端和比例。 工具与构建 · UART4 波形观察
  2. 保持桥关，在机械装置允许手转时慢慢沿规定的正方向转轴。观察 ch3 的单圈机械角是否上升，以及跨圈时是否从接近 2π 回到 0。注明手转的是电机轴还是输出轴。调整方向后需重新构建，并重做角度标定。
  3. 按上一节的低电压短时开环步骤试转，记录相序、实际转向和三相电流波形。三相和接近零可以作为一致性检查，再用引脚映射和 3.6 的坐标验算确认各相。LAB3 的 ch4 是由测量角算出的电角，ch5 是开环给定电角。完成电零点以前，先观察变化方向和连续性。若有故障、转子卡住或电流明显异常，立即停机。 LAB3 六通道映射 · 3.6 开环波形验算
