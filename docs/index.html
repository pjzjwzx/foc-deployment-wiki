怎么使用这份 Wiki

  • 对照仿真。 从 3.1 开始，继续用自己的电压、占空比和角度波形对照固件。
  • 构建固件。 按 3.1 的工具手册导入并构建。CubeMX 部分用 STM32H743 作示范，换器件时按实际定时器、触发和关断接口配置。
  • 准备上板。 先核对板卡、电机与电源条件，再进入 3.3 的操作流程。软件构建及 CAN 离线预览已经核对，实机试转待验证。
